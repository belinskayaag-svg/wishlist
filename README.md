# Wishlist

Сайт-вишлист. Страница — `index.html`, маленький сервер — `server.js`.
Сервер отдаёт страницу и по ссылке на товар подтягивает фото, название и цену
(`/api/preview?url=…`).

## Как выложить на Dockhost

Dockhost собирает сайт из Git-репозитория по `Dockerfile`.

1. Положи папку `wishlist` в отдельный репозиторий на GitHub (или в любой Git).
   В корне репозитория должны лежать `index.html`, `server.js`, `Dockerfile`, `package.json`.
2. В Dockhost: **Новый проект** → название → **Создать**.
3. **Репозитории Git** → **Добавить** → адрес репозитория и ветка `main`.
   Если репозиторий приватный — заполни авторизацию. **Применить**.
4. Подожди, пока появится галочка сборки. Контейнер появится в разделе **Контейнеры**.
5. Порт приложения — **8080** (если панель спрашивает порт или нужно открыть его наружу).
6. Привяжи домен/адрес к контейнеру на порт 8080 — и открой сайт.

После каждого `git push` Dockhost пересобирает и перезапускает сайт сам.

Проверить, что сервер жив: `https://<твой-адрес>/health` → `ok`.

## Как работает автозаполнение

| Магазин | Что подтягивается |
|---|---|
| Wildberries | фото и название — почти всегда; цена — если их сервер отдаёт |
| Lamoda, 12 Storeez, большинство обычных магазинов | фото, название, цена — если магазин не блокирует запрос |
| Золотое яблоко, Ozon | часто закрываются проверкой «не робот» → форма попросит заполнить вручную |
| Летуаль | страница собирается в браузере, данных в разметке нет → вручную |

Что не подтянулось, вписываешь руками; категория угадывается по названию.

## Важно про добавленные желания

Желания, добавленные через «+», сохраняются **в браузере, где их добавили**.
Друзья по ссылке видят только список, который вшит в `index.html` (массив `base`).
Чтобы добавленное видели все, следующий шаг — хранить список на сервере
(у Dockhost есть тома для данных) и закрыть добавление паролем.

## Локальный запуск

```bash
node server.js
```

и открыть http://localhost:8080
